# Doprecyzuj

Z zapisu rozmowy do uzgodnionych wymagań, z których każde wskazuje zdanie źródłowe.

Narzędzie dla analityka i konsultanta: wklejasz notatkę albo transkrypt rozmowy z klientem,
dostajesz propozycje wymagań i pytań doprecyzowujących zakotwiczone w konkretnych zdaniach
źródła, przyjmujesz lub poprawiasz, zapisujesz wersję i eksportujesz dokument gotowy do
wysłania klientowi.

**Status:** w budowie od 2026-11-02. Dokumenty produktowe w `context/foundation/`.
